# Changelog

All notable changes to BorgStudio Server. The release workflow adds every release from the titles of its
pull requests; the server shows this file on its *Changelog* page.

## [0.5.0] - 2026-11-25

### New features
- Add Storage Boxes and SSH servers as datastores, and statistics (#22)

## [0.4.0] - 2026-11-25

### New features
- Let LXC installations follow development builds with update --channel (#19)

## [0.3.0] - 2026-11-24

### New features
- Let borg clients back up over SSH, pair apps and use API tokens (#16)
- Add datastores and repositories with sharing, quotas and trash (#15)

## [0.2.0] - 2026-11-24

### New features
- Add a changelog and update notices (#12)
- Show password rules while typing, start dark, explain recovery codes (#11)

## [0.1.1] - 2026-11-24

### Fixes
- Use the template of the host's architecture and remove failed containers (#8)

## [0.1.0] - 2026-11-24

### New features
- Add an update command for LXC and a friendlier installer output (#5)
- Add HTTPS, install scripts, container image and release workflow (#4)
- Add user management, invitation links and server settings (#3)
- Add sign-in with setup wizard, two-factor authentication and recovery (#2)
- Add the Clean Architecture solution scaffold (#1)
